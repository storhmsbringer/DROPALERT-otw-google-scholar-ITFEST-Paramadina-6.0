# DropAlert — app.py (revisi)

## Menjalankan
1. Pastikan `app.py` dan `dropalert_cluster_provinsi.csv` berada di folder yang sama.
2. (Opsional, untuk fitur Prediksi Risiko & EDA per-tahun) letakkan `Dataset_Gabungan_Fix.xlsx`
   di folder yang sama, atau unggah lewat sidebar saat aplikasi berjalan.
3. Install dependency: `pip install streamlit pandas numpy plotly scikit-learn xgboost openpyxl`
4. Jalankan: `streamlit run app.py`

## Yang berubah dari app.py lama
Lihat docstring di bagian atas app.py ("CATATAN REVISI PENTING") untuk ringkasan lengkap.
